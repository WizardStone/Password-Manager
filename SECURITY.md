# Security Policy

## Risks to the User

All user data is saved to `localStorage` and vulnerable to exterior viewing. Saving any information to this service is ENTIRELY AT YOUR OWN RISK.

## Reporting any Vulnerabilities

If you have a vulnerability to report, please email:
security.password-manager.github@wizardstone.anonaddy.com with the subject exactly 
```
Security Password Manager GitHub
```
If we don't reply open an issue saying you emailed and email again. When this project exits security support, there will be a `no security support` banner
Tell them where to go, how often they can expect to get an update on a
reported vulnerability, what to expect if the vulnerability is accepted or
declined, etc.
